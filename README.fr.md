SDK officiel pour construire des **plugins**, **connecteurs**, **extensions** et **intégrations** pour [Blueprin](blueprin-app.vercel.app) — la plateforme professionnelle de budgétisation architecturale pour la construction en Indonésie.

## Installation

```bash
npm install @alvinahmad/blueprin-sdk
# ou
pnpm add @alvinahmad/blueprin-sdk
# ou
yarn add @alvinahmad/blueprin-sdk
```

## Démarrage rapide

```javascript
import { BlueprinSDK } from '@alvinahmad/blueprin-sdk';

const sdk = new BlueprinSDK({
  appId: 'my-app',
  supabaseUrl: process.env.SUPABASE_URL,
  supabaseKey: process.env.SUPABASE_ANON_KEY,
  debug: true,
});

await sdk.init();

console.log(sdk.getInfo());
// { version: '1.0.0', plugins: 0, hooks: 0, events: 0, initialized: true }
```

## Premier Plugin

```javascript
import { definePlugin } from '@alvinahmad/blueprin-sdk';

export default definePlugin({
  id: 'my-first-plugin',
  name: 'Mon Premier Plugin',
  version: '1.0.0',
  description: 'Mon premier plugin Blueprin',

  activate(ctx) {
    // Écouter les événements
    ctx.events.on('blueprin:project:created', (data) => {
      console.log('Projet créé:', data.project.name);
    });

    // Enregistrer les hooks
    ctx.hooks.register('blueprin:after:rab:calculate', (data) => {
      console.log('Total RAB:', data.result.total);
      return data;
    });

    // Retourner l'API du plugin
    return {
      api: {
        getVersion: () => '1.0.0',
      },
    };
  },

  deactivate(instance) {
    console.log('Plugin désactivé');
  },
});
```

## Créer un Nouveau Plugin

La façon la plus simple de créer un nouveau plugin (avec TypeScript, Vitest et la bonne structure de dossiers) est d'utiliser notre CLI officielle :

```bash
npx create-blueprin-plugin my-plugin
cd my-plugin
npm install
npm run dev
```

Cela clonera automatiquement le [blueprint_plugin_template](https://github.com/qalvinahmad/blueprint_plugin_template), configurera les IDs et noms des plugins, et préparera tout pour le développement.

## Fonctionnalités

- **Système de Plugins** — Enregistrer, activer, désactiver et gérer les plugins avec des hooks de cycle de vie
- **Bus d'Événements** — Système pub/sub pour la communication entre plugins
- **Registre de Hooks** — Hooks before/after le cycle de vie pour étendre les fonctionnalités
- **Adaptateur de Stockage** — Stockage hybride localStorage + Supabase avec protections SSR
- **Clients Domaine** — Modules Projet, Matériel, RAB, Calendrier, Marketplace et Auth
- **Composants UI** — Composants React pour construire les interfaces des plugins
- **SDK Connecteur** — Construire des intégrations avec des services externes
- **Support TypeScript** — Définitions de types complètes incluses

## Référence API

### BlueprinSDK

| Propriété | Type | Description |
|-----------|------|-------------|
| `plugins` | `PluginManager` | Gestion du cycle de vie des plugins |
| `events` | `EventBus` | Système d'événements pub/sub |
| `hooks` | `HookRegistry` | Hooks before/after le cycle de vie |
| `storage` | `StorageAdapter` | Stockage localStorage + Supabase |
| `config` | `ConfigManager` | Configuration des plugins |
| `logger` | `Logger` | Journalisation de débogage |

### PluginManager

| Méthode | Description |
|---------|-------------|
| `register(manifest)` | Enregistrer un nouveau plugin |
| `activate(pluginId)` | Activer un plugin |
| `deactivate(pluginId)` | Désactiver un plugin |
| `remove(pluginId)` | Supprimer un plugin |
| `activateAll()` | Activer tous les plugins |
| `list()` | Lister tous les plugins enregistrés |
| `get(pluginId)` | Obtenir un plugin par ID |

### Modules Domaine

| Module | Description |
| :--- | :--- |
| `ProjectClient` | Informations principales du projet, statut, membres de l'équipe |
| `MaterialClient` | Gestion BOM, catalogue de matériaux, équipements |
| `RabClient` | Budgétisation, relevé de quantités, pipelines de coûts |
| `ScheduleClient` | Planification, calendriers, phases |
| `MarketplaceClient` | Approvisionnement, RFQ, intégrations fournisseurs |
| `WorkforceClient` | Travailleurs, présence, paie |

### EventBus

| Méthode | Description |
|---------|-------------|
| `on(event, callback)` | S'abonner à un événement |
| `once(event, callback)` | S'abonner une fois |
| `off(event, callback)` | Se désabonner |
| `emit(event, data)` | Émettre un événement |

### HookRegistry

| Méthode | Description |
|---------|-------------|
| `register(hook, callback)` | Enregistrer un hook |
| `unregister(hook, callback)` | Annuler l'enregistrement d'un hook |
| `execute(hook, context)` | Exécuter tous les callbacks du hook |

## Noms des Événements

| Événement | Description |
|-----------|-------------|
| `blueprin:project:created` | Projet créé |
| `blueprin:project:updated` | Projet mis à jour |
| `blueprin:project:deleted` | Projet supprimé |
| `blueprin:material:created` | Matériau créé |
| `blueprin:material:updated` | Matériau mis à jour |
| `blueprin:rab:calculated` | RAB calculé |
| `blueprin:rab:expanded` | RAB étendu aux matériaux/main-d'œuvre |
| `blueprin:schedule:generated` | Calendrier généré |
| `blueprin:task:completed` | Tâche terminée |
| `blueprin:marketplace:order:created` | Commande marketplace créée |
| `blueprin:marketplace:rfq:received` | RFQ reçu |
| `blueprin:marketplace:partner:registered` | Partenaire enregistré |
| `blueprin:auth:signed:in` | Utilisateur connecté |
| `blueprin:auth:signed:out` | Utilisateur déconnecté |

## Noms des Hooks

| Hook | Quand |
|------|-------|
| `blueprin:before:project:create` | Avant la création du projet |
| `blueprin:after:project:create` | Après la création du projet |
| `blueprin:before:rab:calculate` | Avant le calcul RAB |
| `blueprin:after:rab:calculate` | Après le calcul RAB |
| `blueprin:before:material:create` | Avant la création du matériau |
| `blueprin:after:material:create` | Après la création du matériau |
| `blueprin:before:order:create` | Avant la création de la commande |
| `blueprin:after:order:create` | Après la création de la commande |
| `blueprin:before:export` | Avant l'exportation du rapport |
| `blueprin:after:export` | Après l'exportation du rapport |

## Moteur de Formules

Blueprin fournit un moteur de calcul extensible dans le module RAB, permettant aux développeurs d'injecter des règles mathématiques personnalisées à divers stades du calcul budgétaire.

```javascript
// Enregistrer une formule de marge bénéficiaire personnalisée de 10%
sdk.rab.formulas.registerProfit('standard-margin', async (context) => {
  return context.baseTotal * 0.10; // 10% de profit
});

// Enregistrer une formule de taxe de 11%
sdk.rab.formulas.registerTax('ppn', async (context) => {
  return context.currentTotal * 0.11;
});
```

Pipelines disponibles : `coefficient`, `escalation`, `allowance`, `overhead`, `profit`, `tax`.

## Main-d'Œuvre et Paie

Un module dédié à la gestion des travailleurs de la construction et au calcul des salaires.

```javascript
// 1. Ajouter un travailleur
const worker = await sdk.workforce.addWorker(projectId, {
  name: 'Budi Tukang',
  role: 'TUKANG',
  daily_rate: 150000,
  overtime_rate: 20000
});

// 2. Enregistrer la présence
await sdk.workforce.logAttendance(projectId, worker.id, '2026-08-04', 'PRESENT', 2); // 2 heures supplémentaires

// 3. Calculer les salaires pour une période
const wages = await sdk.workforce.calculateWages(projectId, '2026-08-01', '2026-08-31');
```

## SDK Connecteur

```javascript
import { BaseConnector } from '@alvinahmad/blueprin-sdk';

class MyConnector extends BaseConnector {
  static protocol = 'rest';

  async connect(config) {
    this.client = new MyClient(config.apiKey);
    return this;
  }

  async disconnect() {
    this.client = null;
  }

  async fetchData() {
    return this.client.get('/data');
  }
}
```

## Composants UI

> **Note :** Blueprin est une plateforme basée sur React. Les plugins UI et composants injectés via le SDK doivent être construits avec **React 18+**. Si vous prévoyez de supporter Vue ou Svelte à l'avenir, vous devrez envelopper vos composants d'interface en Web Components (Custom Elements) ou fournir des bindings séparés.

```jsx
import {
  BlueprintButton,
  BlueprintCard,
  BlueprintBadge,
  BlueprintTable,
  BlueprintInput,
  BlueprintSelect,
  BlueprintModal,
  BlueprintToast,
  BlueprintSkeleton,
} from '@alvinahmad/blueprin-sdk/ui';

// Utiliser dans votre plugin UI
export default function MyPluginUI() {
  return (
    <BlueprintCard>
      <BlueprintBadge variant="success">Actif</BlueprintBadge>
      <BlueprintButton variant="primary">Cliquez ici</BlueprintButton>
    </BlueprintCard>
  );
}
```

## Sécurité et Sandboxing

Le SDK Blueprin implémente un sandboxing strict pour protéger l'application hôte :
- **Timeouts des Hooks** : Tous les hooks des plugins ont une limite d'exécution stricte (max `200ms`) pour éviter les boucles infinies ou le blocage de l'interface.
- **Requêtes Réseau** : Les plugins **ne sont pas autorisés** à effectuer des requêtes vers des domaines externes sauf si explicitement autorisés par l'application hôte via les permissions du manifeste.

Pour les vulnérabilités ou préoccupations de sécurité, veuillez consulter notre [Politique de Sécurité](SECURITY.md).
