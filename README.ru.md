Официальный SDK для создания **плагинов**, **коннекторов**, **расширений** и **интеграций** для [Blueprin](blueprin-app.vercel.app) — профессиональная платформа архитектурного бюджетирования для строительства в Индонезии.

## Установка

```bash
npm install @alvinahmad/blueprin-sdk
# или
pnpm add @alvinahmad/blueprin-sdk
# или
yarn add @alvinahmad/blueprin-sdk
```

## Быстрый старт

```javascript
import { BlueprinSDK } from '@alvinahmad/blueprin-sdk';

const sdk = new BlueprinSDK({
  appId: 'my-app',
  supabaseUrl: process.env.SUPABASE_URL,
  supabaseKey: process.env.SUPABASE_ANON_KEY,
  debug: true,
});

await sdk.init();

console.log(sdk.getInfo());
// { version: '1.0.0', plugins: 0, hooks: 0, events: 0, initialized: true }
```

## Первый плагин

```javascript
import { definePlugin } from '@alvinahmad/blueprin-sdk';

export default definePlugin({
  id: 'my-first-plugin',
  name: 'Мой первый плагин',
  version: '1.0.0',
  description: 'Мой первый плагин для Blueprin',

  activate(ctx) {
    // Слушать события
    ctx.events.on('blueprin:project:created', (data) => {
      console.log('Проект создан:', data.project.name);
    });

    // Регистрировать хуки
    ctx.hooks.register('blueprin:after:rab:calculate', (data) => {
      console.log('Итого RAB:', data.result.total);
      return data;
    });

    // Вернуть API плагина
    return {
      api: {
        getVersion: () => '1.0.0',
      },
    };
  },

  deactivate(instance) {
    console.log('Плагин деактивирован');
  },
});
```

## Создание нового плагина

Самый простой способ создать новый плагин (с TypeScript, Vitest и правильной структурой папок) — использовать наш официальный CLI:

```bash
npx create-blueprin-plugin my-plugin
cd my-plugin
npm install
npm run dev
```

Это автоматически склонирует [blueprint_plugin_template](https://github.com/qalvinahmad/blueprint_plugin_template), настроит ID и имена плагинов и подготовит всё к разработке.

## Возможности

- **Система плагинов** — Регистрация, активация, деактивация и управление плагинами с хуками жизненного цикла
- **Шина событий** — Система pub/sub для межплагинного взаимодействия
- **Реестр хуков** — Хуки before/after жизненного цикла для расширения функциональности
- **Адаптер хранилища** — Гибридное хранилище localStorage + Supabase с защитой SSR
- **Доменные клиенты** — Модули Проект, Материал, RAB, Расписание, Маркетплейс и Авторизация
- **UI компоненты** — React компоненты для создания интерфейсов плагинов
- **SDK коннекторов** — Создание интеграций с внешними сервисами
- **Поддержка TypeScript** — Полные определения типов включены

## Справочник API

### BlueprinSDK

| Свойство | Тип | Описание |
|----------|-----|----------|
| `plugins` | `PluginManager` | Управление жизненным циклом плагинов |
| `events` | `EventBus` | Система событий pub/sub |
| `hooks` | `HookRegistry` | Хуки before/after жизненного цикла |
| `storage` | `StorageAdapter` | Хранилище localStorage + Supabase |
| `config` | `ConfigManager` | Конфигурация плагинов |
| `logger` | `Logger` | Журналирование отладки |

### PluginManager

| Метод | Описание |
|-------|----------|
| `register(manifest)` | Зарегистрировать новый плагин |
| `activate(pluginId)` | Активировать плагин |
| `deactivate(pluginId)` | Деактивировать плагин |
| `remove(pluginId)` | Удалить плагин |
| `activateAll()` | Активировать все плагины |
| `list()` | Список всех зарегистрированных плагинов |
| `get(pluginId)` | Получить плагин по ID |

### Доменные модули

| Модуль | Описание |
| :--- | :--- |
| `ProjectClient` | Основная информация о проекте, статус, участники команды |
| `MaterialClient` | Управление BOM, каталог материалов, оборудование |
| `RabClient` | Бюджетирование, сметное ценообразование, конвейеры成本 |
| `ScheduleClient` | Планирование, графики, фазы |
| `MarketplaceClient` | Закупки, RFQ, интеграция с поставщиками |
| `WorkforceClient` | Рабочие, посещаемость, расчёт заработной платы |

### EventBus

| Метод | Описание |
|-------|----------|
| `on(event, callback)` | Подписаться на событие |
| `once(event, callback)` | Подписаться один раз |
| `off(event, callback)` | Отписаться |
| `emit(event, data)` | Инициировать событие |

### HookRegistry

| Метод | Описание |
|-------|----------|
| `register(hook, callback)` | Зарегистрировать хук |
| `unregister(hook, callback)` | Отменить регистрацию хука |
| `execute(hook, context)` | Выполнить все колбэки хука |

## Названия событий

| Событие | Описание |
|---------|----------|
| `blueprin:project:created` | Проект создан |
| `blueprin:project:updated` | Проект обновлён |
| `blueprin:project:deleted` | Проект удалён |
| `blueprin:material:created` | Материал создан |
| `blueprin:material:updated` | Материал обновлён |
| `blueprin:rab:calculated` | RAB рассчитан |
| `blueprin:rab:expanded` | RAB расширен до материалов/рабочей силы |
| `blueprin:schedule:generated` | Расписание сгенерировано |
| `blueprin:task:completed` | Задача выполнена |
| `blueprin:marketplace:order:created` | Заказ на маркетплейсе создан |
| `blueprin:marketplace:rfq:received` | RFQ получен |
| `blueprin:marketplace:partner:registered` | Партнёр зарегистрирован |
| `blueprin:auth:signed:in` | Пользователь вошёл |
| `blueprin:auth:signed:out` | Пользователь вышел |

## Названия хуков

| Хук | Когда |
|-----|-------|
| `blueprin:before:project:create` | Перед созданием проекта |
| `blueprin:after:project:create` | После создания проекта |
| `blueprin:before:rab:calculate` | Перед расчётом RAB |
| `blueprin:after:rab:calculate` | После расчёта RAB |
| `blueprin:before:material:create` | Перед созданием материала |
| `blueprin:after:material:create` | После создания материала |
| `blueprin:before:order:create` | Перед созданием заказа |
| `blueprin:after:order:create` | После создания заказа |
| `blueprin:before:export` | Перед экспортом отчёта |
| `blueprin:after:export` | После экспорта отчёта |

## Движок формул

Blueprin предоставляет расширяемый вычислительный движок внутри модуля RAB, позволяющий разработчикам внедрять пользовательские математические правила на различных этапах бюджетных расчётов.

```javascript
// Зарегистрировать пользовательскую формулу маржи прибыли 10%
sdk.rab.formulas.registerProfit('standard-margin', async (context) => {
  return context.baseTotal * 0.10; // 10% прибыли
});

// Зарегистрировать формулу налога 11%
sdk.rab.formulas.registerTax('ppn', async (context) => {
  return context.currentTotal * 0.11;
});
```

Доступные конвейеры: `coefficient`, `escalation`, `allowance`, `overhead`, `profit`, `tax`.

## Рабочая сила и расчёт заработной платы

Выделенный модуль для управления строительными рабочими и расчёта заработной платы.

```javascript
// 1. Добавить рабочего
const worker = await sdk.workforce.addWorker(projectId, {
  name: 'Budi Tukang',
  role: 'TUKANG',
  daily_rate: 150000,
  overtime_rate: 20000
});

// 2. Записать посещаемость
await sdk.workforce.logAttendance(projectId, worker.id, '2026-08-04', 'PRESENT', 2); // 2 часа сверхурочной работы

// 3. Рассчитать заработную плату за период
const wages = await sdk.workforce.calculateWages(projectId, '2026-08-01', '2026-08-31');
```

## SDK коннекторов

```javascript
import { BaseConnector } from '@alvinahmad/blueprin-sdk';

class MyConnector extends BaseConnector {
  static protocol = 'rest';

  async connect(config) {
    this.client = new MyClient(config.apiKey);
    return this;
  }

  async disconnect() {
    this.client = null;
  }

  async fetchData() {
    return this.client.get('/data');
  }
}
```

## UI компоненты

> **Примечание:** Blueprin — это платформа на базе React. UI плагины и компоненты, внедряемые через SDK, должны быть построены с использованием **React 18+**. Если вы планируете поддерживать Vue или Svelte в будущем, вам нужно будет обернуть ваши UI компоненты как Web Components (Custom Elements) или предоставить отдельные привязки.

```jsx
import {
  BlueprintButton,
  BlueprintCard,
  BlueprintBadge,
  BlueprintTable,
  BlueprintInput,
  BlueprintSelect,
  BlueprintModal,
  BlueprintToast,
  BlueprintSkeleton,
} from '@alvinahmad/blueprin-sdk/ui';

// Использовать в UI плагине
export default function MyPluginUI() {
  return (
    <BlueprintCard>
      <BlueprintBadge variant="success">Активен</BlueprintBadge>
      <BlueprintButton variant="primary">Нажмите здесь</BlueprintButton>
    </BlueprintCard>
  );
}
```

## Безопасность и песочница

Blueprin SDK реализует строгую песочницу для защиты хост-приложения:
- **Тайм-ауты хуков**: Все хуки плагинов имеют строгий лимит выполнения (макс. `200мс`) для предотвращения бесконечных циклов или блокировки интерфейса.
- **Сетевые запросы**: Плагинам **не разрешено** выполнять запросы к внешним доменам, если они не явно разрешены хост-приложением через разрешения манифеста.

По вопросам уязвимостей или безопасности см. нашу [Политику безопасности](SECURITY.md).
