Offizielles SDK zum Erstellen von **Plugins**, **Connectoren**, **Erweiterungen** und **Integrationen** für [Blueprin](blueprin-app.vercel.app) — die professionelle architektonische Budgetierungsplattform für das Bauwesen in Indonesien.

## Installation

```bash
npm install @alvinahmad/blueprin-sdk
# oder
pnpm add @alvinahmad/blueprin-sdk
# oder
yarn add @alvinahmad/blueprin-sdk
```

## Schnellstart

```javascript
import { BlueprinSDK } from '@alvinahmad/blueprin-sdk';

const sdk = new BlueprinSDK({
  appId: 'my-app',
  supabaseUrl: process.env.SUPABASE_URL,
  supabaseKey: process.env.SUPABASE_ANON_KEY,
  debug: true,
});

await sdk.init();

console.log(sdk.getInfo());
// { version: '1.0.0', plugins: 0, hooks: 0, events: 0, initialized: true }
```

## Erstes Plugin

```javascript
import { definePlugin } from '@alvinahmad/blueprin-sdk';

export default definePlugin({
  id: 'my-first-plugin',
  name: 'Mein Erstes Plugin',
  version: '1.0.0',
  description: 'Mein erstes Blueprin-Plugin',

  activate(ctx) {
    // Events hören
    ctx.events.on('blueprin:project:created', (data) => {
      console.log('Projekt erstellt:', data.project.name);
    });

    // Hooks registrieren
    ctx.hooks.register('blueprin:after:rab:calculate', (data) => {
      console.log('RAB-Gesamt:', data.result.total);
      return data;
    });

    // Plugin-API zurückgeben
    return {
      api: {
        getVersion: () => '1.0.0',
      },
    };
  },

  deactivate(instance) {
    console.log('Plugin deaktiviert');
  },
});
```

## Neues Plugin Erstellen

Der einfachste Weg, ein neues Plugin zu erstellen (mit TypeScript, Vitest und der richtigen Ordnerstruktur), ist die Verwendung unseres offiziellen CLI-Tools:

```bash
npx create-blueprin-plugin my-plugin
cd my-plugin
npm install
npm run dev
```

Dies klon automatisch die [blueprint_plugin_template](https://github.com/qalvinahmad/blueprint_plugin_template), richtet die Plugin-IDs und Namen ein und bereitet alles für die Entwicklung vor.

## Funktionen

- **Plugin-System** — Plugins mit Lifecycle-Hooks registrieren, aktivieren, deaktivieren und verwalten
- **Event-Bus** — Pub/Sub-System zur Inter-Plugin-Kommunikation
- **Hook-Registry** — Before/After-Lifecycle-Hooks zur Funktionalitätserweiterung
- **Storage-Adapter** — Hybrid-Speicherung localStorage + Supabase mit SSR-Schutz
- **Domain-Clients** — Module Projekt, Material, RAB, Zeitplan, Marketplace und Auth
- **UI-Komponenten** — React-Komponenten zum Erstellen von Plugin-Oberflächen
- **Connector-SDK** — Integrationen mit externen Diensten aufbauen
- **TypeScript-Unterstützung** — Vollständige Tydefinitionen enthalten

## API-Referenz

### BlueprinSDK

| Eigenschaft | Typ | Beschreibung |
|-------------|-----|--------------|
| `plugins` | `PluginManager` | Plugin-Lifecycle-Verwaltung |
| `events` | `EventBus` | Pub/Sub-Event-System |
| `hooks` | `HookRegistry` | Before/After-Lifecycle-Hooks |
| `storage` | `StorageAdapter` | localStorage + Supabase-Speicherung |
| `config` | `ConfigManager` | Plugin-Konfiguration |
| `logger` | `Logger` | Debug-Protokollierung |

### PluginManager

| Methode | Beschreibung |
|---------|--------------|
| `register(manifest)` | Neues Plugin registrieren |
| `activate(pluginId)` | Plugin aktivieren |
| `deactivate(pluginId)` | Plugin deaktivieren |
| `remove(pluginId)` | Plugin entfernen |
| `activateAll()` | Alle Plugins aktivieren |
| `list()` | Alle registrierten Plugins auflisten |
| `get(pluginId)` | Plugin per ID abrufen |

### Domain-Module

| Modul | Beschreibung |
| :--- | :--- |
| `ProjectClient` | Hauptprojektinformationen, Status, Teammitglieder |
| `MaterialClient` | BOM-Verwaltung, Materialkatalog, Ausrüstung |
| `RabClient` | Budgetierung, Mengenermittlung, Kosten-Pipelines |
| `ScheduleClient` | Zeitplanung, Zeitachsen, Phasen |
| `MarketplaceClient` | Beschaffung, RFQ, Lieferanten-Integrationen |
| `WorkforceClient` | Arbeiter, Anwesenheit, Gehaltsabrechnung |

### EventBus

| Methode | Beschreibung |
|---------|--------------|
| `on(event, callback)` | Einem Event abonnieren |
| `once(event, callback)` | Einmal abonnieren |
| `off(event, callback)` | Abonnement kündigen |
| `emit(event, data)` | Event auslösen |

### HookRegistry

| Methode | Beschreibung |
|---------|--------------|
| `register(hook, callback)` | Hook registrieren |
| `unregister(hook, callback)` | Hook-Registrierung aufheben |
| `execute(hook, context)` | Alle Hook-Callbacks ausführen |

## Event-Namen

| Event | Beschreibung |
|-------|--------------|
| `blueprin:project:created` | Projekt erstellt |
| `blueprin:project:updated` | Projekt aktualisiert |
| `blueprin:project:deleted` | Projekt gelöscht |
| `blueprin:material:created` | Material erstellt |
| `blueprin:material:updated` | Material aktualisiert |
| `blueprin:rab:calculated` | RAB berechnet |
| `blueprin:rab:expanded` | RAB auf Materialien/Arbeitskräfte erweitert |
| `blueprin:schedule:generated` | Zeitplan generiert |
| `blueprin:task:completed` | Aufgabe abgeschlossen |
| `blueprin:marketplace:order:created` | Marketplace-Bestellung erstellt |
| `blueprin:marketplace:rfq:received` | RFQ erhalten |
| `blueprin:marketplace:partner:registered` | Partner registriert |
| `blueprin:auth:signed:in` | Benutzer angemeldet |
| `blueprin:auth:signed:out` | Benutzer abgemeldet |

## Hook-Namen

| Hook | Wann |
|------|------|
| `blueprin:before:project:create` | Vor der Projekterstellung |
| `blueprin:after:project:create` | Nach der Projekterstellung |
| `blueprin:before:rab:calculate` | Vor der RAB-Berechnung |
| `blueprin:after:rab:calculate` | Nach der RAB-Berechnung |
| `blueprin:before:material:create` | Vor der Materialerstellung |
| `blueprin:after:material:create` | Nach der Materialerstellung |
| `blueprin:before:order:create` | Vor der Bestellungserstellung |
| `blueprin:after:order:create` | Nach der Bestellungserstellung |
| `blueprin:before:export` | Vor dem Berichtsexport |
| `blueprin:after:export` | Nach dem Berichtsexport |

## Formel-Engine

Blueprin bietet eine erweiterbare Berechnungsengine im RAB-Modul, die Entwicklern ermöglicht, benutzerdefinierte mathematische Regeln in verschiedenen Phasen der Budgetberechnung zu injizieren.

```javascript
// Benutzerdefinierte 10% Gewinnmargen-Formel registrieren
sdk.rab.formulas.registerProfit('standard-margin', async (context) => {
  return context.baseTotal * 0.10; // 10% Gewinn
});

// 11% Steuerformel registrieren
sdk.rab.formulas.registerTax('ppn', async (context) => {
  return context.currentTotal * 0.11;
});
```

Verfügbare Pipelines: `coefficient`, `escalation`, `allowance`, `overhead`, `profit`, `tax`.

## Arbeitskräfte & Gehaltsabrechnung

Ein dediziertes Modul zur Verwaltung von Bauarbeitern und Berechnung von Löhnen.

```javascript
// 1. Arbeiter hinzufügen
const worker = await sdk.workforce.addWorker(projectId, {
  name: 'Budi Tukang',
  role: 'TUKANG',
  daily_rate: 150000,
  overtime_rate: 20000
});

// 2. Anwesenheit protokollieren
await sdk.workforce.logAttendance(projectId, worker.id, '2026-08-04', 'PRESENT', 2); // 2 Stunden Überstunden

// 3. Löhne für einen Zeitraum berechnen
const wages = await sdk.workforce.calculateWages(projectId, '2026-08-01', '2026-08-31');
```

## Connector-SDK

```javascript
import { BaseConnector } from '@alvinahmad/blueprin-sdk';

class MyConnector extends BaseConnector {
  static protocol = 'rest';

  async connect(config) {
    this.client = new MyClient(config.apiKey);
    return this;
  }

  async disconnect() {
    this.client = null;
  }

  async fetchData() {
    return this.client.get('/data');
  }
}
```

## UI-Komponenten

> **Hinweis:** Blueprin ist eine React-basierte Plattform. UI-Plugins und über das SDK injizierte Komponenten müssen mit **React 18+** erstellt werden. Wenn Sie Vue oder Svelte unterstützen möchten, müssen Sie Ihre UI-Komponenten als Web Components (Custom Elements) verpacken oder separate Bindings bereitstellen.

```jsx
import {
  BlueprintButton,
  BlueprintCard,
  BlueprintBadge,
  BlueprintTable,
  BlueprintInput,
  BlueprintSelect,
  BlueprintModal,
  BlueprintToast,
  BlueprintSkeleton,
} from '@alvinahmad/blueprin-sdk/ui';

// In Ihrem UI-Plugin verwenden
export default function MyPluginUI() {
  return (
    <BlueprintCard>
      <BlueprintBadge variant="success">Aktiv</BlueprintBadge>
      <BlueprintButton variant="primary">Klicken Sie hier</BlueprintButton>
    </BlueprintCard>
  );
}
```

## Sicherheit & Runtime-Sandboxing

Das Blueprin SDK implementiert striktes Runtime-Sandboxing zum Schutz der Host-App:
- **Hook-Timeouts**: Alle Plugin-Hooks haben eine strenge Ausführungsgrenze (max `200ms`) um Endlosschleifen oder UI-Blockierungen zu verhindern.
- **Netzwerkanfragen**: Plugins dürfen **keine** externen Domains abfragen, es sei denn, sie wurden explizit durch die Host-App über die Manifest-Berechtigungen freigegeben.

Für Schwachstellen oder weitere Sicherheitsbedenken lesen Sie bitte unsere [Sicherheitsrichtlinie](SECURITY.md).
