SDK oficial para construir **plugins**, **conectores**, **extensiones** e **integraciones** para [Blueprin](blueprin-app.vercel.app) — la plataforma profesional de presupuestación arquitectónica para construcción en Indonesia.

## Instalación

```bash
npm install @alvinahmad/blueprin-sdk
# o
pnpm add @alvinahmad/blueprin-sdk
# o
yarn add @alvinahmad/blueprin-sdk
```

## Inicio Rápido

```javascript
import { BlueprinSDK } from '@alvinahmad/blueprin-sdk';

const sdk = new BlueprinSDK({
  appId: 'my-app',
  supabaseUrl: process.env.SUPABASE_URL,
  supabaseKey: process.env.SUPABASE_ANON_KEY,
  debug: true,
});

await sdk.init();

console.log(sdk.getInfo());
// { version: '1.0.0', plugins: 0, hooks: 0, events: 0, initialized: true }
```

## Primer Plugin

```javascript
import { definePlugin } from '@alvinahmad/blueprin-sdk';

export default definePlugin({
  id: 'my-first-plugin',
  name: 'Mi Primer Plugin',
  version: '1.0.0',
  description: 'Mi primer plugin para Blueprin',

  activate(ctx) {
    // Escuchar eventos
    ctx.events.on('blueprin:project:created', (data) => {
      console.log('Proyecto creado:', data.project.name);
    });

    // Registrar hooks
    ctx.hooks.register('blueprin:after:rab:calculate', (data) => {
      console.log('Total RAB:', data.result.total);
      return data;
    });

    // Devolver API del plugin
    return {
      api: {
        getVersion: () => '1.0.0',
      },
    };
  },

  deactivate(instance) {
    console.log('Plugin desactivado');
  },
});
```

## Crear un Nuevo Plugin

La forma más fácil de crear un nuevo plugin (con TypeScript, Vitest y la estructura de carpetas correcta) es usar nuestra CLI oficial:

```bash
npx create-blueprin-plugin my-plugin
cd my-plugin
npm install
npm run dev
```

Esto clonará automáticamente la [blueprint_plugin_template](https://github.com/qalvinahmad/blueprint_plugin_template), configurará los IDs y nombres de los plugins, y preparará todo para el desarrollo.

## Características

- **Sistema de Plugins** — Registrar, activar, desactivar y gestionar plugins con hooks de ciclo de vida
- **Bus de Eventos** — Sistema pub/sub para la comunicación entre plugins
- **Registro de Hooks** — Hooks before/after del ciclo de vida para extender funcionalidad
- **Adaptador de Almacenamiento** — Almacenamiento híbrido localStorage + Supabase con protecciones SSR
- **Clientes de Dominio** — Módulos Proyecto, Material, RAB, Calendario, Marketplace y Auth
- **Componentes UI** — Componentes React para construir interfaces de plugins
- **SDK de Conectores** — Construir integraciones con servicios externos
- **Soporte TypeScript** — Definiciones de tipos completas incluidas

## Referencia API

### BlueprinSDK

| Propiedad | Tipo | Descripción |
|-----------|------|-------------|
| `plugins` | `PluginManager` | Gestión del ciclo de vida de plugins |
| `events` | `EventBus` | Sistema de eventos pub/sub |
| `hooks` | `HookRegistry` | Hooks before/after del ciclo de vida |
| `storage` | `StorageAdapter` | Almacenamiento localStorage + Supabase |
| `config` | `ConfigManager` | Configuración de plugins |
| `logger` | `Logger` | Registro de depuración |

### PluginManager

| Método | Descripción |
|--------|-------------|
| `register(manifest)` | Registrar un nuevo plugin |
| `activate(pluginId)` | Activar un plugin |
| `deactivate(pluginId)` | Desactivar un plugin |
| `remove(pluginId)` | Eliminar un plugin |
| `activateAll()` | Activar todos los plugins |
| `list()` | Listar todos los plugins registrados |
| `get(pluginId)` | Obtener plugin por ID |

### Módulos de Dominio

| Módulo | Descripción |
| :--- | :--- |
| `ProjectClient` | Información principal del proyecto, estado, miembros del equipo |
| `MaterialClient` | Gestión BOM, catálogo de materiales, equipamiento |
| `RabClient` | Presupuestación, levantamiento de cantidades, pipelines de costos |
| `ScheduleClient` | Programación, cronogramas, fases |
| `MarketplaceClient` | Adquisiciones, RFQ, integraciones con proveedores |
| `WorkforceClient` | Trabajadores, asistencia, nómina |

### EventBus

| Método | Descripción |
|--------|-------------|
| `on(event, callback)` | Suscribirse a un evento |
| `once(event, callback)` | Suscribirse una vez |
| `off(event, callback)` | Cancelar suscripción |
| `emit(event, data)` | Emitir un evento |

### HookRegistry

| Método | Descripción |
|--------|-------------|
| `register(hook, callback)` | Registrar un hook |
| `unregister(hook, callback)` | Cancelar registro de un hook |
| `execute(hook, context)` | Ejecutar todos los callbacks del hook |

## Nombres de Eventos

| Evento | Descripción |
|--------|-------------|
| `blueprin:project:created` | Proyecto creado |
| `blueprin:project:updated` | Proyecto actualizado |
| `blueprin:project:deleted` | Proyecto eliminado |
| `blueprin:material:created` | Material creado |
| `blueprin:material:updated` | Material actualizado |
| `blueprin:rab:calculated` | RAB calculado |
| `blueprin:rab:expanded` | RAB expandido a materiales/mano de obra |
| `blueprin:schedule:generated` | Calendario generado |
| `blueprin:task:completed` | Tarea completada |
| `blueprin:marketplace:order:created` | Orden de marketplace creada |
| `blueprin:marketplace:rfq:received` | RFQ recibido |
| `blueprin:marketplace:partner:registered` | Socio registrado |
| `blueprin:auth:signed:in` | Usuario conectado |
| `blueprin:auth:signed:out` | Usuario desconectado |

## Nombres de Hooks

| Hook | Cuándo |
|------|--------|
| `blueprin:before:project:create` | Antes de la creación del proyecto |
| `blueprin:after:project:create` | Después de la creación del proyecto |
| `blueprin:before:rab:calculate` | Antes del cálculo RAB |
| `blueprin:after:rab:calculate` | Después del cálculo RAB |
| `blueprin:before:material:create` | Antes de la creación del material |
| `blueprin:after:material:create` | Después de la creación del material |
| `blueprin:before:order:create` | Antes de la creación de la orden |
| `blueprin:after:order:create` | Después de la creación de la orden |
| `blueprin:before:export` | Antes de la exportación del reporte |
| `blueprin:after:export` | Después de la exportación del reporte |

## Motor de Fórmulas

Blueprin proporciona un motor de cálculo extensible dentro del módulo RAB, permitiendo a los desarrolladores inyectar reglas matemáticas personalizadas en varias etapas del cálculo presupuestario.

```javascript
// Registrar una fórmula de margen de beneficio personalizada del 10%
sdk.rab.formulas.registerProfit('standard-margin', async (context) => {
  return context.baseTotal * 0.10; // 10% de beneficio
});

// Registrar una fórmula de impuesto del 11%
sdk.rab.formulas.registerTax('ppn', async (context) => {
  return context.currentTotal * 0.11;
});
```

Pipelines disponibles: `coefficient`, `escalation`, `allowance`, `overhead`, `profit`, `tax`.

## Fuerza Laboral y Nómina

Un módulo dedicado para gestionar trabajadores de construcción y calcular salarios.

```javascript
// 1. Agregar un trabajador
const worker = await sdk.workforce.addWorker(projectId, {
  name: 'Budi Tukang',
  role: 'TUKANG',
  daily_rate: 150000,
  overtime_rate: 20000
});

// 2. Registrar asistencia
await sdk.workforce.logAttendance(projectId, worker.id, '2026-08-04', 'PRESENT', 2); // 2 horas extra

// 3. Calcular salarios para un período
const wages = await sdk.workforce.calculateWages(projectId, '2026-08-01', '2026-08-31');
```

## SDK de Conectores

```javascript
import { BaseConnector } from '@alvinahmad/blueprin-sdk';

class MyConnector extends BaseConnector {
  static protocol = 'rest';

  async connect(config) {
    this.client = new MyClient(config.apiKey);
    return this;
  }

  async disconnect() {
    this.client = null;
  }

  async fetchData() {
    return this.client.get('/data');
  }
}
```

## Componentes UI

> **Nota:** Blueprin es una plataforma basada en React. Los plugins UI y componentes inyectados a través del SDK deben construirse usando **React 18+**. Si planea soportar Vue o Svelte en el futuro, necesitará envolver sus componentes de interfaz como Web Components (Custom Elements) o proporcionar bindings separados.

```jsx
import {
  BlueprintButton,
  BlueprintCard,
  BlueprintBadge,
  BlueprintTable,
  BlueprintInput,
  BlueprintSelect,
  BlueprintModal,
  BlueprintToast,
  BlueprintSkeleton,
} from '@alvinahmad/blueprin-sdk/ui';

// Usar en su plugin UI
export default function MyPluginUI() {
  return (
    <BlueprintCard>
      <BlueprintBadge variant="success">Activo</BlueprintBadge>
      <BlueprintButton variant="primary">Haz Clic Aquí</BlueprintButton>
    </BlueprintCard>
  );
}
```

## Seguridad y Sandboxing

El SDK Blueprin implementa un sandboxing estricto para proteger la aplicación anfitriona:
- **Timeouts de Hooks**: Todos los hooks de plugins tienen un límite de ejecución estricto (máx `200ms`) para prevenir bucles infinitos o bloqueos de interfaz.
- **Solicitudes de Red**: Los plugins **no están autorizados** a hacer fetch a dominios externos a menos que estén explícitamente autorizados por la aplicación anfitriona a través de los permisos del manifiesto.

Para vulnerabilidades o preocupaciones de seguridad, consulte nuestra [Política de Seguridad](SECURITY.md).
