SDK oficial para construir **plugins**, **conectores**, **extensões** e **integrações** para [Blueprin](blueprin-app.vercel.app) — a plataforma profissional de orçamentação arquitetônica para construção na Indonésia.

## Instalação

```bash
npm install @alvinahmad/blueprin-sdk
# ou
pnpm add @alvinahmad/blueprin-sdk
# ou
yarn add @alvinahmad/blueprin-sdk
```

## Início Rápido

```javascript
import { BlueprinSDK } from '@alvinahmad/blueprin-sdk';

const sdk = new BlueprinSDK({
  appId: 'my-app',
  supabaseUrl: process.env.SUPABASE_URL,
  supabaseKey: process.env.SUPABASE_ANON_KEY,
  debug: true,
});

await sdk.init();

console.log(sdk.getInfo());
// { version: '1.0.0', plugins: 0, hooks: 0, events: 0, initialized: true }
```

## Primeiro Plugin

```javascript
import { definePlugin } from '@alvinahmad/blueprin-sdk';

export default definePlugin({
  id: 'my-first-plugin',
  name: 'Meu Primeiro Plugin',
  version: '1.0.0',
  description: 'Meu primeiro plugin para Blueprin',

  activate(ctx) {
    // Ouvir eventos
    ctx.events.on('blueprin:project:created', (data) => {
      console.log('Projeto criado:', data.project.name);
    });

    // Registrar hooks
    ctx.hooks.register('blueprin:after:rab:calculate', (data) => {
      console.log('Total RAB:', data.result.total);
      return data;
    });

    // Retornar API do plugin
    return {
      api: {
        getVersion: () => '1.0.0',
      },
    };
  },

  deactivate(instance) {
    console.log('Plugin desativado');
  },
});
```

## Criar um Novo Plugin

A maneira mais fácil de criar um novo plugin (com TypeScript, Vitest e a estrutura de pastas correta) é usar nossa CLI oficial:

```bash
npx create-blueprin-plugin my-plugin
cd my-plugin
npm install
npm run dev
```

Isso clonará automaticamente a [blueprint_plugin_template](https://github.com/qalvinahmad/blueprint_plugin_template), configurará os IDs e nomes dos plugins e preparará tudo para o desenvolvimento.

## Funcionalidades

- **Sistema de Plugins** — Registrar, ativar, desativar e gerenciar plugins com hooks de ciclo de vida
- **Bus de Eventos** — Sistema pub/sub para comunicação entre plugins
- **Registro de Hooks** — Hooks before/after do ciclo de vida para estender funcionalidades
- **Adaptador de Armazenamento** — Armazenamento híbrido localStorage + Supabase com proteção SSR
- **Clientes de Domínio** — Módulos Projeto, Material, RAB, Agenda, Marketplace e Auth
- **Componentes UI** — Componentes React para construir interfaces de plugins
- **SDK Conector** — Construir integrações com serviços externos
- **Suporte TypeScript** — Definições de tipos completas incluídas

## Referência API

### BlueprinSDK

| Propriedade | Tipo | Descrição |
|-------------|------|-----------|
| `plugins` | `PluginManager` | Gerenciamento do ciclo de vida de plugins |
| `events` | `EventBus` | Sistema de eventos pub/sub |
| `hooks` | `HookRegistry` | Hooks before/after do ciclo de vida |
| `storage` | `StorageAdapter` | Armazenamento localStorage + Supabase |
| `config` | `ConfigManager` | Configuração de plugins |
| `logger` | `Logger` | Registro de depuração |

### PluginManager

| Método | Descrição |
|--------|-----------|
| `register(manifest)` | Registrar um novo plugin |
| `activate(pluginId)` | Ativar um plugin |
| `deactivate(pluginId)` | Desativar um plugin |
| `remove(pluginId)` | Remover um plugin |
| `activateAll()` | Ativar todos os plugins |
| `list()` | Listar todos os plugins registrados |
| `get(pluginId)` | Obter plugin por ID |

### Módulos de Domínio

| Módulo | Descrição |
| :--- | :--- |
| `ProjectClient` | Informações principais do projeto, status, membros da equipe |
| `MaterialClient` | Gestão BOM, catálogo de materiais, equipamentos |
| `RabClient` | Orçamentação, levantamento de quantidades, pipelines de custos |
| `ScheduleClient` | Agendamento, cronogramas, fases |
| `MarketplaceClient` | Licitações, RFQ, integrações com fornecedores |
| `WorkforceClient` | Trabalhadores, presença, folha de pagamento |

### EventBus

| Método | Descrição |
|--------|-----------|
| `on(event, callback)` | Assinar um evento |
| `once(event, callback)` | Assinar uma vez |
| `off(event, callback)` | Cancelar assinatura |
| `emit(event, data)` | Emitir um evento |

### HookRegistry

| Método | Descrição |
|--------|-----------|
| `register(hook, callback)` | Registrar um hook |
| `unregister(hook, callback)` | Cancelar registro de um hook |
| `execute(hook, context)` | Executar todos os callbacks do hook |

## Nomes de Eventos

| Evento | Descrição |
|--------|-----------|
| `blueprin:project:created` | Projeto criado |
| `blueprin:project:updated` | Projeto atualizado |
| `blueprin:project:deleted` | Projeto excluído |
| `blueprin:material:created` | Material criado |
| `blueprin:material:updated` | Material atualizado |
| `blueprin:rab:calculated` | RAB calculado |
| `blueprin:rab:expanded` | RAB expandido para materiais/mão de obra |
| `blueprin:schedule:generated` | Agenda gerada |
| `blueprin:task:completed` | Tarefa concluída |
| `blueprin:marketplace:order:created` | Pedido do marketplace criado |
| `blueprin:marketplace:rfq:received` | RFQ recebido |
| `blueprin:marketplace:partner:registered` | Parceiro registrado |
| `blueprin:auth:signed:in` | Usuário conectado |
| `blueprin:auth:signed:out` | Usuário desconectado |

## Nomes de Hooks

| Hook | Quando |
|------|--------|
| `blueprin:before:project:create` | Antes da criação do projeto |
| `blueprin:after:project:create` | Após a criação do projeto |
| `blueprin:before:rab:calculate` | Antes do cálculo RAB |
| `blueprin:after:rab:calculate` | Após o cálculo RAB |
| `blueprin:before:material:create` | Antes da criação do material |
| `blueprin:after:material:create` | Após a criação do material |
| `blueprin:before:order:create` | Antes da criação do pedido |
| `blueprin:after:order:create` | Após a criação do pedido |
| `blueprin:before:export` | Antes da exportação do relatório |
| `blueprin:after:export` | Após a exportação do relatório |

## Motor de Fórmulas

Blueprin fornece um motor de cálculo extensível dentro do módulo RAB, permitindo que desenvolvedores injetem regras matemáticas personalizadas em várias etapas do cálculo orçamentário.

```javascript
// Registrar uma fórmula de margem de lucro personalizada de 10%
sdk.rab.formulas.registerProfit('standard-margin', async (context) => {
  return context.baseTotal * 0.10; // 10% de lucro
});

// Registrar uma fórmula de imposto de 11%
sdk.rab.formulas.registerTax('ppn', async (context) => {
  return context.currentTotal * 0.11;
});
```

Pipelines disponíveis: `coefficient`, `escalation`, `allowance`, `overhead`, `profit`, `tax`.

## Mão de Obra e Folha de Pagamento

Um módulo dedicado para gerenciar trabalhadores da construção e calcular salários.

```javascript
// 1. Adicionar um trabalhador
const worker = await sdk.workforce.addWorker(projectId, {
  name: 'Budi Tukang',
  role: 'TUKANG',
  daily_rate: 150000,
  overtime_rate: 20000
});

// 2. Registrar presença
await sdk.workforce.logAttendance(projectId, worker.id, '2026-08-04', 'PRESENT', 2); // 2 horas extras

// 3. Calcular salários para um período
const wages = await sdk.workforce.calculateWages(projectId, '2026-08-01', '2026-08-31');
```

## SDK Conector

```javascript
import { BaseConnector } from '@alvinahmad/blueprin-sdk';

class MyConnector extends BaseConnector {
  static protocol = 'rest';

  async connect(config) {
    this.client = new MyClient(config.apiKey);
    return this;
  }

  async disconnect() {
    this.client = null;
  }

  async fetchData() {
    return this.client.get('/data');
  }
}
```

## Componentes UI

> **Nota:** Blueprin é uma plataforma baseada em React. Plugins UI e componentes injetados via SDK devem ser construídos usando **React 18+**. Se você planeja suportar Vue ou Svelte no futuro, precisará envolver seus componentes de interface como Web Components (Custom Elements) ou fornecer bindings separados.

```jsx
import {
  BlueprintButton,
  BlueprintCard,
  BlueprintBadge,
  BlueprintTable,
  BlueprintInput,
  BlueprintSelect,
  BlueprintModal,
  BlueprintToast,
  BlueprintSkeleton,
} from '@alvinahmad/blueprin-sdk/ui';

// Usar na interface do seu plugin
export default function MyPluginUI() {
  return (
    <BlueprintCard>
      <BlueprintBadge variant="success">Ativo</BlueprintBadge>
      <BlueprintButton variant="primary">Clique Aqui</BlueprintButton>
    </BlueprintCard>
  );
}
```

## Segurança e Sandboxing

O Blueprin SDK implementa sandboxing rigoroso para proteger a aplicação hospedeira:
- **Timeouts de Hooks**: Todos os hooks dos plugins têm um limite de execução estrito (máx `200ms`) para prevenir loops infinitos ou bloqueios de interface.
- **Requisições de Rede**: Plugins **não são autorizados** a buscar domínios externos, a menos que sejam explicitamente autorizados pela aplicação hospedeira através das permissões do manifesto.

Para vulnerabilidades ou preocupações de segurança, consulte nossa [Política de Segurança](SECURITY.md).
